## Mise à jour de la documentation (règle permanente)

À **chaque modification** du projet, avant de conclure, mettre à jour tous les fichiers `.md` concernés :
- `docs/DECISIONS.md` : décisions prises (contexte, choix, raison), sous la date du jour.
- `docs/PATTERNS.md` : patterns et conventions introduits ou modifiés.
- `docs/ERREURS.md` : erreurs corrigées (symptôme, cause, correction, prévention).
- `README.md` : commandes, fonctionnalités, dépannage si changés.
- `AGENTS.md` : si une règle de travail change.

Ajouter, ne pas réécrire l'historique ; dater les entrées (AAAA-MM-JJ) ; rester concis ; ne pas dupliquer ce que le code dit déjà.
